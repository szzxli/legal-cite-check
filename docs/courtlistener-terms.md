# CourtListener terms (summary — read the source)

Source: https://free.law/membership/allowed-api-usage/ (read 2026-10-26;
see VERIFICATION.md for the full verification record).

- Membership-based API access is intended for personal, educational,
  research, journalistic, and exploratory use.
- Solo practitioners and law firms with **five or fewer attorneys**
  are welcome to use membership-based API access.
- Small government use, small pre-revenue unfunded organizations, and
  journalists are welcome (with the caveats on that page).
- Membership-based API access **may not** be used to power a
  revenue-positive commercial product, service, or feature — whether
  sold directly, offered as part of a subscription, or included as a
  benefit of something else sold.
- Membership-based API access is for small firms only. More than five
  attorneys: discuss a commercial agreement instead.
- Membership-based API access **may not** be used to build tools for
  for-profit or non-profit organizations, even if those tools aren't
  sold outside the company. Free Law Project considers internal
  tooling that supports an organization's operation to be commercial use.
- One person, one account. Do not create multiple accounts to expand
  access. Do not share API keys across people or organizations.
- Commercial users should contact Free Law Project's partnerships team
  to set up an agreement.

Consequence for this project: this prototype is free, open-source, and
not sold. **No commercial use until a separate agreement is signed.**
The README tells every user that their own token is subject to these
terms, and that large firms / organizations need their own agreement.
If this tool ever becomes revenue-positive or is built as internal
tooling for an organization, stop and get that agreement first.
