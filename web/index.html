legal-cite-check

Does the case you cited exist in CourtListener, and is it the case you named? Paste text below. This page only extracts citations in your browser — it does not look anything up.

Not legal advice. This tool only checks whether a cited case exists in CourtListener and whether the case name matches. It does not check whether the case supports your argument, whether quotes or pin cites are accurate, or whether the case is still good law. A case marked NOT FOUND may still exist (CourtListener's coverage is incomplete); a case marked VERIFIED may still be wrong for your purpose. Read every case you cite.

#CitationCase name in textLabelManual-check links

How to run the full check

The full check needs the Python CLI and your own free CourtListener token (see the README). It sends only the extracted citation strings by default, never your brief text.

pip install .
python -m legalcite check brief.md --md report.md
# with: COURTLISTENER_TOKEN set in your environment
